# 📝 Todo Application (Frontend)

A simple and responsive Todo Application built using HTML, CSS, JavaScript, and Bootstrap. This app allows users to manage daily tasks efficiently using LocalStorage.

## 📌 Features

- ✅ Add new todos  
- ✅ Mark todos as completed  
- ✅ Delete todos  
- ✅ Persistent storage using LocalStorage  
- ✅ Responsive UI using Bootstrap  
- ✅ Simple and user-friendly interface  

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- Bootstrap  
- JavaScript (ES6)  
- LocalStorage  

---

## 📂 Project Structure

/project-folder  

├── index.html

├── index.css

├── index.js


---

## ⚙️ How it Works

- Todos are stored in **LocalStorage**
- On page load, saved todos are fetched and displayed
- User actions update both UI and LocalStorage
